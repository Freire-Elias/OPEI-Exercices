# 🧠 OPEI - Treinamento para a Olimpíada Pernambucana de Informática

Repositório criado para armazenar minhas soluções e estudos dos desafios passados da **OPEI (Olimpíada Pernambucana de Informática)**.

O objetivo deste projeto é praticar lógica de programação, algoritmos e resolução de problemas competitivos através das questões das edições anteriores da olimpíada.

---

## 📚 Conteúdo

Este repositório inclui:

- Soluções de problemas de edições passadas da OPEI
- Exercícios de treino
- Implementações de algoritmos úteis para programação competitiva
- Estudos e testes pessoais

---

## 🛠️ Tecnologias utilizadas

As soluções podem utilizar linguagens como:

- C++
- Python
